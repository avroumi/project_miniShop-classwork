# Mini Shop

A small e-commerce application built with React and TypeScript.

## Features

- Product list from Fake Store API
- Product search
- Product details page
- Favorites system with Zustand
- Persistent favorites with localStorage
- Light / Dark theme with Context API
- React Router navigation
- Loading, error and empty states

## Technologies

- React
- TypeScript
- Vite
- React Router
- Axios
- Zustand
- Context API
- CSS

## Run the project

```bash
npm install
npm run dev
```
